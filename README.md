# Screen Recorder (Windows)

Трей-приложение для Windows: запись экрана (+опционально микрофона и системного
звука) через ffmpeg и автоматическая транскрипция записи через Groq Whisper API
(с таймкодами, в `.docx`). Windows-аналог
[ranlywood/screen-recorder](https://github.com/ranlywood/screen-recorder).

## Скачать и установить

Возьми `ScreenRecorder-Setup.exe` со страницы [Releases](../../releases) этого
репозитория, запусти и следуй мастеру установки. Права администратора не
нужны — ставится в папку текущего пользователя. ffmpeg уже встроен в
установщик, отдельно ставить ничего не надо.

> **При первом запуске Windows покажет предупреждение SmartScreen** («Windows
> защитила ваш компьютер») — это ожидаемо, установщик не подписан платным
> сертификатом разработчика. Нажми **«Дополнительно»** → **«Выполнить в любом
> случае»**, чтобы продолжить установку.

После установки появится иконка в трее (серый кружок). Правый клик по ней:

- **Начать запись (экран)** — только видео экрана, `.mp4`.
- **Начать запись (экран + микрофон)** — видео экрана + звук с микрофона.
- **Начать запись (экран + микрофон + системный звук)** — то же самое плюс
  всё, что играет через колонки/наушники (собеседник в Zoom/Teams, звук
  видео в браузере и т.п.). Полезно для записи звонков, где нужно услышать
  обе стороны разговора.
- **Остановить запись** — корректно завершает запись и сохраняет файл в
  `Видео → Recordings`.
- **Настроить Groq-ключ...** — открывает окно для ввода API-ключа Groq
  (нужен только для автоматической транскрипции; сама запись работает и без
  него). Ключ бесплатный, получить можно на
  [console.groq.com/keys](https://console.groq.com/keys) — инструкция есть
  прямо в этом окне. При первом запуске без ключа окно откроется само.
- **Открыть папку с записями**.
- **Выход**.

Если ключ настроен, после остановки записи в фоне запускается транскрипция:
аудиодорожка извлекается и отправляется в Groq с таймкодами
(`response_format=verbose_json`). Результат — `{имя_записи}_transcript.docx`
рядом с самой записью, с таймкодом перед каждой репликой.

## Для разработчиков

```powershell
pip install -r requirements.txt
python tray_app.py
```

Groq-ключ для запуска из исходников можно положить в `.env`
(`GROQ_API_KEY=...`) рядом с `tray_app.py`, либо настроить через то же меню
трея — оно сохраняет ключ в `%APPDATA%\ScreenRecorderWin\config.json`
независимо от режима запуска (так и работает установленная версия, у неё
нет `.env`).

ffmpeg при запуске из исходников ищется на `PATH`, через
`winget install --id Gyan.FFmpeg -e`, либо по пути из переменной окружения
`SCREENRECORDER_FFMPEG`.

## Сборка установщика

Нужны `pyinstaller` (`pip install pyinstaller`) и
[Inno Setup 6](https://jrsoftware.org/isinfo.php).

```powershell
python -m PyInstaller --noconfirm --windowed --name ScreenRecorder `
  --add-binary "<путь_к_ffmpeg.exe>;." `
  --add-binary "<путь_к_ffprobe.exe>;." `
  tray_app.py

& "C:\Users\<you>\AppData\Local\Programs\Inno Setup 6\ISCC.exe" installer.iss
```

Готовый `ScreenRecorder-Setup.exe` появится в `installer_output/`.

## Известные ограничения (отличия от macOS-оригинала)

- Системный звук захватывается через WASAPI loopback (`PyAudioWPatch`) с
  устройства вывода по умолчанию — записывается то же, что слышит
  пользователь. Если во время записи переключить устройство вывода (например,
  подключить/отключить наушники), захват продолжит писать со старого
  устройства до следующего запуска записи.
- Захват экрана идёт через `gdigrab` (просто и надёжно), а не через более
  быстрый `ddagrab`/Windows.Graphics.Capture — для обычных задач записи экрана
  разницы почти не заметно, но на очень высоких FPS/разрешениях gdigrab может
  немного отставать.
- Микрофон выбирается автоматически (первое устройство из списка DirectShow).
  Чтобы задать конкретное устройство, узнай его точное имя:
  ```powershell
  <путь_к_ffmpeg> -list_devices true -f dshow -i dummy
  ```
  и укажи в `.env` (или `%APPDATA%\ScreenRecorderWin\config.json` как
  `mic_device`): `SCREENRECORDER_MIC_DEVICE = Имя устройства`.
- Только Windows. macOS-пользователям — оригинальный
  [ranlywood/screen-recorder](https://github.com/ranlywood/screen-recorder).
